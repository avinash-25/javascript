🔧 How setTimeout() Works

setTimeout() is part of the Web APIs, not core JavaScript. It works with:

  • Call Stack: Where functions execute
  • Web APIs: Where timers run
  • Task Queue: Where callbacks wait
  • Event Loop: Manages execution order
setTimeout(() => { console.log("This runs after 1 second"); }, 1000);

⚠️ Common Pitfalls

Be aware of these common issues:

  • Variable Scope: Use let/const instead of var in loops
  • Timing: Delays aren't guaranteed to be exact
  • Memory Leaks: Always clear unused timeouts
  • Background Throttling: Delays increase in inactive tabs
// ❌ Problem with var for (var i = 0; i < 3; i++) { setTimeout(() => console.log(i), 100); // Prints: 3,3,3 } // ✅ Solution with let for (let i = 0; i < 3; i++) { setTimeout(() => console.log(i), 100); // Prints: 0,1,2 }

🚀 Best Practices

Follow these guidelines for better code:

  • Clean Code: Use descriptive function names
  • Error Handling: Wrap callbacks in try-catch
  • Cleanup: Store and clear timeout IDs
  • Performance: Avoid excessive timeouts
// Store timeout ID for cleanup const timeoutId = setTimeout(() => { try { // Your code here console.log("Safe execution"); } catch (error) { console.error("Error:", error); } }, 1000); // Clear if needed clearTimeout(timeoutId);

🎯 Real-World Use Cases

setTimeout() is commonly used for:

  • Debouncing: Limit function calls frequency
  • Animation: Create smooth transitions
  • API Delays: Prevent rate limiting
  • User Experience: Progressive loading
// Debounce example function debounce(func, delay) { let timeoutId; return function(...args) { clearTimeout(timeoutId); timeoutId = setTimeout(() => func.apply(this, args), delay); }; }

📊 Performance Tips

Optimize your setTimeout() usage:

  • Implement proper cleanup in SPAs

🔗 Related Functions

setTimeout() family of functions:

  • setInterval(): Repeats execution
  • clearTimeout(): Cancels a timeout
  • clearInterval(): Cancels an interval
  • requestAnimationFrame(): For smooth animations
