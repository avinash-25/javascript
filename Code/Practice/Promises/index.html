📚 Step 1: Understanding Promise States

⏳ Pending

Promise is working...

✅ Fulfilled

Promise succeeded!

❌ Rejected

Promise failed!

🔧 Step 2: Creating Your First Promise

Simple Promise that always succeeds:

const simplePromise = new Promise((resolve, reject) => { setTimeout(() => { resolve("Success! Promise completed!"); }, 2000); }); // Using the promise simplePromise.then(result => { console.log(result); });
Click the button to see the result...

⚡ Step 3: Promise with Success and Error Handling

const randomPromise = new Promise((resolve, reject) => { setTimeout(() => { const random = Math.random(); if (random > 0.5) { resolve(`Success! Random number: ${random}`); } else { reject(`Failed! Random number too low: ${random}`); } }, 1000); }); randomPromise .then(result => console.log("✅", result)) .catch(error => console.log("❌", error));
Click to test success/failure...

🔄 Step 4: Chaining Promises

Process data step by step:

function step1(data) { return new Promise(resolve => { setTimeout(() => { resolve(data + " → Step 1 completed"); }, 1000); }); } function step2(data) { return new Promise(resolve => { setTimeout(() => { resolve(data + " → Step 2 completed"); }, 1000); }); } // Chain them together Promise.resolve("Starting") .then(step1) .then(step2) .then(result => console.log("Final result:", result));
Watch the chain execute...

🚀 Step 5: Multiple Promises Together

Promise.all() - Wait for all promises:

const promise1 = new Promise(resolve => setTimeout(() => resolve("Data 1"), 1000)); const promise2 = new Promise(resolve => setTimeout(() => resolve("Data 2"), 2000)); const promise3 = new Promise(resolve => setTimeout(() => resolve("Data 3"), 1500)); Promise.all([promise1, promise2, promise3]) .then(results => { console.log("All completed:", results); });
All promises will complete together...

⚡ Step 6: Real-World Example - Fake API Call

function fetchUserData(userId) { return new Promise((resolve, reject) => { console.log(`Fetching user ${userId}...`); setTimeout(() => { if (userId > 0) { resolve({ id: userId, name: `User ${userId}`, email: `user${userId}@example.com` }); } else { reject("Invalid user ID"); } }, 1500); }); } // Usage fetchUserData(123) .then(user => { console.log("User found:", user); return fetchUserData(456); // Chain another call }) .then(user2 => { console.log("Second user:", user2); }) .catch(error => { console.log("Error:", error); });
Simulating real API calls...

🎭 Step 7: Async/Await - The Modern Way

Same logic, cleaner syntax:

async function getUsersModernWay() { try { console.log("Starting async function..."); const user1 = await fetchUserData(789); console.log("Got first user:", user1.name); const user2 = await fetchUserData(101); console.log("Got second user:", user2.name); return "Both users loaded successfully!"; } catch (error) { console.log("Something went wrong:", error); } } getUsersModernWay() .then(result => console.log("Final:", result));
See the modern async/await syntax...
